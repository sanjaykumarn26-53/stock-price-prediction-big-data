Top 10 stocks, forecasted.

Real daily closing prices for 10 of the world’s largest companies. Each model is trained on the first 80% of 500 trading days, tested on the last 20%, then used to forecast the days ahead.

Each row uses its best model of the three (lowest test RMSE) with the window and forecast days chosen below. “vs naive” compares test RMSE with simply repeating yesterday’s price. Grey changes come from models that did not beat the naive baseline, so treat them as unreliable. Select a row to see its chart.

Workflow

Problem definitionPredict the next day’s closing price and a multi-day outlook.
Data collectionReal daily closes for 10 companies, or your own CSV.
Storage & processingHeld in browser memory here. A full build would use Spark or HDFS.
TrainingFirst 80% of days, in time order, so nothing leaks from the future.
EvaluationLast 20% scored with RMSE, MAE, R² and direction accuracy.
DeploymentThis interactive page.
Built by Sanjay Kumar N as a companion to the report “Stock Price Prediction Using Big Data”. Prices: daily closes, split-adjusted, from the public dataset github.com/yennanliu/finance_data (data used up to 30 Apr 2025, matching the project period). Apple and Berkshire Hathaway were not in that dataset, so Oracle and Palantir are included instead. Forecasts are statistical demos, not predictions to trade on, and not financial advice.
