# Stock Price Prediction Using Big Data

Research and workflow design for predicting stock prices using big data and machine learning.

## Overview
This academic project explores how big data and machine learning can be used for stock price forecasting. It reviews published research and proposes an end-to-end workflow, from data collection to model monitoring.

## Workflow
1. Problem definition and target variable
2. Data collection (historical prices, news, sentiment, economic indicators)
3. Data storage and processing
4. Data preprocessing and feature engineering
5. Exploratory data analysis
6. Model selection and training (Linear Regression, Random Forest, XGBoost, LSTM)
7. Model evaluation (RMSE, MAE, R²) and time-series validation (walk-forward, backtesting)
8. Deployment and monitoring
